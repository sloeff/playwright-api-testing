# Introduction

Welcome to the Playwright API Testing repository! This project is designed to provide exercises for testing APIs using Playwright. Solutions can be found in the solutions folder

# Getting Started

1. Clone the repository
2. Run 'npm install' in the terminal

# Exercises

1. GET call
2. Parse response to a JSON object
3. Storing value to a variable
4. POST and GET call
5. Factory pattern
